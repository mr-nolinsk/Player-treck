# 🕺 Body Tracker Addon

**body_tracker_addon** — аддон для Blender, который позволяет отслеживать движения человека по видео или с подключённой камеры и переносить их на 3D-модель.

Аддон помогает создавать анимации персонажей на основе реальных движений человека без необходимости вручную анимировать каждую кость.

## ✨ Возможности

* 🎥 Отслеживание человека по видео
* 📷 Отслеживание движений с подключённой камеры
* 🧍 Распознавание положения и движений тела
* 🎭 Перенос движений на 3D-модель
* 🦴 Выбор и настройка костей модели
* 🎯 Выбор модели для анимации
* 🎬 Создание анимации на основе отслеженных движений
* ⚙️ Настройка соответствия частей тела и костей

## 🔄 Как это работает

Работа аддона состоит из нескольких этапов:

### 1. Выбор модели

В меню `body_tracker_addon` выбирается 3D-модель, которая должна повторять движения человека.

### 2. Настройка костей

Пользователь указывает соответствие между частями тела человека и костями выбранной модели.

Например:

```text
Голова             → Head
Шея                → Neck
Позвоночник        → Spine
Левое плечо        → Upper Arm.L
Правое плечо       → Upper Arm.R
Левое предплечье   → Forearm.L
Правое предплечье  → Forearm.R
Левая кисть        → Hand.L
Правая кисть       → Hand.R
Левое бедро        → Thigh.L
Правое бедро       → Thigh.R
Левая голень       → Shin.L
Правая голень      → Shin.R
```

### 3. Выбор источника

Можно выбрать источник движения:

**📹 Видео**

Загрузить заранее записанное видео человека.

**📷 Камера**

Подключить камеру и отслеживать движения человека непосредственно перед ней.

### 4. Отслеживание

Аддон анализирует движение человека и определяет положение основных частей тела.

### 5. Перенос движения

Полученные данные применяются к костям выбранной модели.

В результате 3D-персонаж повторяет движения человека.

## 🎬 Пример использования

Допустим, у вас есть 3D-персонаж с Armature.

1. Откройте Blender.
2. Установите `body_tracker_addon`.
3. Откройте панель аддона.
4. Выберите персонажа.
5. Укажите соответствующие кости.
6. Выберите источник движения.
7. Загрузите видео или подключите камеру.
8. Запустите отслеживание.
9. Дождитесь обработки.
10. Получите анимацию персонажа.

После обработки полученную анимацию можно редактировать стандартными инструментами Blender.

## 📦 Установка

1. Скачайте репозиторий или ZIP-архив проекта.
2. Откройте **Blender**.
3. Перейдите в:

```text
Edit → Preferences → Add-ons
```

4. Нажмите **Install...**
5. Выберите ZIP-файл аддона.
6. Включите `body_tracker_addon`.

> ⚠️ Если Blender устанавливает аддон из ZIP, не распаковывайте архив перед установкой.

## 🦴 Требования к модели

Для переноса движений модель должна иметь **Armature / Rig**.

Перед началом работы необходимо настроить соответствие между костями модели и отслеживаемыми частями тела.

Разные модели могут использовать разные названия костей, поэтому настройка костей может потребоваться вручную.

## 📹 Источники движения

### Видео

Видео можно использовать для создания готовой анимации из заранее записанного движения.

Подходит для:

* создания анимаций персонажей;
* motion capture;
* обработки записанных движений;
* экспериментов с анимацией.

### Камера

Камера позволяет отслеживать движения человека в реальном времени.

Это может использоваться для управления 3D-персонажем непосредственно во время движения.
